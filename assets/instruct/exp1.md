To evaluate the efficiency of AnchorMerge, we compare it with existing token pruning methods on a high-resolution MLLM LLaVA-NeXT-Vicuna-7B~\cite{llavanext}. We consider five efficiency metrics: FLOPs, E2E latency, prefilling time, and GPU memory consumption. All experiments are conducted on a single NVIDIA H20 GPU. We evaluate all methods on MT-GQA, which contains 4,061 three-turn samples. Each method performs token pruning once, and the pruned visual tokens are reused for answering all subsequent questions.
