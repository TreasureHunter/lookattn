\subsection{Multimodal Large Language Models}
The emergence of powerful reasoning capabilities in large language models (LLMs)~\cite{gpt4,deepseek} has driven research beyond text-only scenarios toward visual understanding, giving rise to multimodal large language models (MLLMs)~\cite{llava1.5,llavanext,qwen3vl}. A typical MLLM consists of three main components: a vision encoder, a multimodal projector, and an LLM. The vision encoder converts an input image into visual features, while the projector projects and aligns these features with the LLM's input space. The resulting visual tokens are then fed into the LLM together with textual tokens for multimodal understanding and generation.
However, the number of visual tokens grows rapidly with the input image resolution or video length, while substantial redundancy exists among these tokens. For example, LLaVA-NeXT~\cite{llavanext} adopts AnyRes technology to support higher-resolution input images, generating 2,880 visual tokens for a 672 $\times$ 672 input image. In video scenarios, LongVA~\cite{longva} can process up to 2,000 frames, resulting in over 200K visual tokens. Such a large number of visual tokens results in a substantial KV cache, posing significant challenges to memory consumption and generation efficiency. 
Therefore, visual token pruning, which aims to enable efficient MLLM inference by removing unimportant visual tokens, has become an important research direction.

\subsection{Visual Token Pruning}
Visual token pruning methods estimate token importance to select relevant visual tokens. The first category is similarity-based methods, which remove redundant tokens based on feature similarity among visual tokens. DivPrune~\cite{divprune} greedily selects visual tokens by maximizing the minimum cosine distance between them, favoring diverse and less redundant tokens. DART~\cite{dart} selects a small set of pivot tokens and prunes redundant visual tokens based on their similarity to the pivots, while HoloV~\cite{holov} adaptively allocates token budgets across image crops based on their visual information distribution to prevent excessive pruning in certain regions. The second category is attention-based methods. FastV~\cite{fastv} identifies important tokens based on attention scores in early layers, while SparseVLM~\cite{sparsevlm} progressively prunes less important tokens layer by layer based on attention scores. HAWK~\cite{hawk} further extends FastV by assigning different weights to attention heads. The third category combines the above two types of methods. VisionZip~\cite{visionzip} selects dominant tokens based on attention scores from the vision encoder and aggregates the remaining ones to form complementary tokens, while CDPruner~\cite{cdpruner} jointly prunes and merges visual tokens by considering their relevance to the user instruction and redundancy among visual tokens. However, these methods rely on heuristic rules, lack robustness across different tasks, and achieve limited performance. In this paper, we address these limitations with a learnable approach.
