In recent years, the rapid progress of large language models (LLMs)~\cite{llm_survey1,llm_survey2,gpt4,deepseek} has driven the advancement of multimodal large language models (MLLMs)~\cite{llava1.5,llavanext,qwen3vl}, extending the powerful reasoning capabilities of LLMs to image and video understanding~\cite{mvbench,vipllava}. However, the practical deployment of MLLMs still faces significant challenges in computational and memory costs~\cite{intro_challenge,visionzip}. High-resolution images and long videos can introduce thousands of visual tokens, which not only inflate prefilling computation but also substantially increase the key-value (KV) cache, consequently resulting in high decoding latency and GPU memory overhead.

Numerous visual token pruning methods reduce computational and memory costs by identifying and removing redundant visual tokens. Existing methods can be classified into three categories: similarity-based, attention-based, and attention\&similarity-based. Similarity-based methods measure similarity among visual tokens to remove redundant ones~\cite{divprune,dart,holov}, while attention-based methods typically use attention scores derived from the user instruction to estimate token importance~\cite{fastv,sparsevlm,hawk}. However, similarity-based methods are query-agnostic and may overlook image details relevant to specific questions, whereas attention-based methods may suffer from attention biases in the early layers, e.g., FastV~\cite{fastv}, where attention scores may be dominated by attention sinks rather than query-relevant visual tokens. Although attention\&similarity-based methods partially alleviate these issues, they rely on heuristic designs and achieve limited performance gains~\cite{visionzip,cdpruner}.

To overcome these limitations, we introduce a learnable strategy for visual token pruning to replace existing heuristic rules, aiming to achieve more accurate and consistent results. Specifically, we observe that attention scores from deeper layers provide a useful signal for estimating visual token importance. However, directly computing these scores incurs additional computational and memory costs, undermining the efficiency of token pruning. To address this issue, we propose XXX, a lightweight, plug-and-play framework that predicts deep-layer attention scores to guide visual token pruning. Specifically, we first identify a precise visual attention head and uses its attention scores in the last layer as supervision signals. XXX is then trained to predict these scores from input visual and textual features, enabling query-aware efficient token importance estimation without explicitly computing deep-layer attention scores.
