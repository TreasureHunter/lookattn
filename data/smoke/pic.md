请使用 Python Matplotlib 生成一张可用于 CVPR 论文的高质量学术图表。

**图表目的：**

展示最终 LLM 层中每个注意力头分配给视觉 token 的注意力总量（$\alpha_h$）与对应视觉 token 筛选准确率之间的关系。

**图表设计：**

- 使用双 Y 轴组合图，即柱状图 + 折线图。
- X 轴：注意力头的索引，覆盖最终 LLM 层中的所有注意力头。
- 左侧 Y 轴：视觉注意力总量（Visual Attention Mass, $\alpha_h$），使用柱状图表示。
- 右侧 Y 轴：Token Selection Accuracy（%），使用带有小圆形标记的折线图表示。
- 每根柱子对应一个注意力头。
- 折线连接各个注意力头对应的准确率数据点。
- 使用协调且容易区分的颜色表示两组数据。
- 对 $\alpha_h$ 最大的注意力头进行适度突出显示，例如使用颜色较深的柱子或细边框。

**绘图风格要求：**

- 采用简洁、紧凑、专业的 CVPR/NeurIPS 论文绘图风格。
- 使用白色背景、纤细的坐标轴和浅色的水平网格线。
- 使用统一且易读的字体，合理设置坐标轴标签、刻度和图例的字号。
- 图例应简洁紧凑，放置在不遮挡数据的位置。
- 避免过多注释、装饰元素、渐变色和 3D 效果。
- 左右两个 Y 轴使用各自独立的数值范围，并明确标注指标名称和单位。
- 使用 tight_layout 优化布局。

**数据接口：**

接受两个长度相同的数组：

1. alpha_values：每个注意力头的视觉注意力总量。
2. accuracy_values：每个注意力头对应的 Token Selection Accuracy。

不得虚构、修改或调整输入数据。

**输出要求：**

同时导出 PDF 矢量格式和高分辨率 PNG 图片。
